# Amstrad PCW8xxx Schematics #
This repository contains a KiCad project representing
the schematics of the main board of the Amstrad
PCW8256 and PCW8512 personal computers

The project is largely complete for schematics only
The multiplexed addressing and RAS/CAS signals to the
DRAM need to be verified as the original schematics
are unreadable in this area
